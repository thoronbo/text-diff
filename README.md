# 文本对比 Text Diff

把两段文本放在一起，逐行、逐字看清改了哪里。

## 能做什么

**并排对比**　左边原文，右边新文，改动行一一对齐。

**逐字高亮**　同一行里只标出真正变化的字符，不用整行重读。

**忽略噪声**　可以选择忽略大小写和空白差异，专注内容本身。

**复制差异**　把改动导出成带 `+` / `-` 标记的文本，贴到邮件或工单里。

## 打开方式

双击 `index.html` 即可使用。两边各粘贴一段文字，差异会立刻显示。

想先看看效果，点右上角的「载入示例」。

## 小提示

- 行号从 1 开始，左侧是原文行号，右侧是新文行号。
- 绿色表示新增，红色表示删除，黄色标记的是被修改的内容。
- 内容特别长时，列表只展示开头部分，复制差异仍然是完整结果。
